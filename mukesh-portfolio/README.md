## How to use
1. Unzip the folder.
2. Open `index.html` directly in any browser — no build step needed.
3. To host it live for free, drag the folder into Netlify Drop
   (https://app.netlify.com/drop) or push it to a GitHub repo and enable
   GitHub Pages.
